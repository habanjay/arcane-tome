# Arcane‑Tome  
A magical, modern expense tracker for the Arcane Suite.

Arcane‑Tome is a lightweight yet powerful expense tracking application designed to help you record transactions, categorize spending, visualize financial trends, and maintain clarity over your personal finances. Built with a clean architecture and a fantasy‑inspired theme, Arcane‑Tome fits seamlessly alongside **Arcane‑Vault** (password manager) and **Arcane‑Ledger** (trade tracker).

---

## ✨ Features

- **Expense Logging**  
  Add, edit, and delete expenses with intuitive forms and category tagging.

- **Category Management**  
  Create custom categories and organize your spending your way.

- **Monthly & Yearly Summaries**  
  View aggregated totals, averages, and spending breakdowns.

- **Charts & Visualizations**  
  Beautiful graphs for trends, category distribution, and spending patterns.

- **Search & Filters**  
  Quickly find transactions by date, category, or keyword.

- **Cross‑Platform Ready**  
  Designed for future integration with mobile, desktop, and web clients.

- **Arcane Suite Integration**  
  Shared design language and optional data sync with Arcane‑Ledger.

---

## 🏗️ Tech Stack

- **Backend:** .NET / Aspire  
- **Frontend:** React (or your chosen UI framework)  
- **Database:** SQLite / PostgreSQL / Azure SQL (configurable)  
- **Auth:** Local or Arcane‑Vault integration (optional)  
- **Deployment:** Azure App Service / Container Apps
